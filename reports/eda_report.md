## 3. Takeaways feeding Phase 3/4

1. **No missing values, no duplicates** in either dataset → no imputation required for #697 (imputer kept in the pipeline anyway as a safety net for future data).
2. **Moderate imbalance in #697 (2.78:1)** and **severe in #320 (5.5:1 fail)** → macro-F1 + per-class recall are the primary metrics; class weights are an experiment, not a default.
3. **Semester features dominate the raw correlation** — and are exactly the ones the leakage audit restricts to H2/H3. Expect H1 models to be noticeably weaker than H2: that gap is the real cost of warning early, and is a headline result.
4. **Skewed count features + different scales** → StandardScaler for SVM/KNN/logistic inside the pipeline; trees unaffected.
5. **IQR outliers flagged but retained** pending per-feature review in Phase 3.
